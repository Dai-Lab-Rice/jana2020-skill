# Single-crystal magnetic refinement

## Propagation vector and reflection import

- Record the propagation vector and its basis. A prediction or indexing vector
  stored in an integration table does not measure the peak center. Use independently
  fitted centers or reciprocal-space profiles to assess whether competing vectors
  can be distinguished. A user-selected working vector can be fixed for the
  refinement and reported as an assumption.
- Check whether distinct satellite branches coincide at the chosen vector.
  Resolve coincidences at the prediction or integration stage, using one
  integration and uncertainty per physical peak in each independent measurement
  context. A repeated measurement from a different exposure can still carry
  independent information. For integrations of overlapping windows, obtain a
  joint estimate with its uncertainty or reintegrate the events. Adding the
  intensities or treating the windows as independent can double-count signal.
- A commensurate supercell is one way to import ordinary integer indices.
  With a single half-order vector along parent c, a doubled-c setting maps
  `(h,k,l,m)` to `(h,k,2l+m)`. Derive the transformation for the actual vector
  and verify Jana's input and model cells, origin, and index mapping. Retain the
  original reflection export. A multi-index satellite export may have a different
  fixed-width layout from a nuclear export. Check field boundaries and confirm
  which index count the selected importer supports before converting a copy.
- After import or symmetry conversion, check the native observation counts,
  signed indices, intensities, uncertainties, wavelengths, and scale and domain
  assignments. When using E-format, regenerate it with Jana and verify the
  actual records. Preserve identities across the input, native files and listing.
  If applying detector or wavelength screens, follow the
  [measurement diagnostics](measurement_diagnostics.md#suspect-observations-and-detector-edges).

## Nuclear anchor and generated constraints

1. Start from a verified nuclear model. Transfer site-specific ADPs and
   coordinates through the actual basis change, including the mapping between
   parent orbits and sites split by lowering the symmetry. Check occupancies
   against multiplicity in the new cell. Use the fundamentals to anchor scales
   and verify that the same normalization applies to the corresponding
   satellites. Track overlaps in scale groups and inspect sparsely supported
   groups before releasing their scales.
2. Inspect the generated restrictions, fixed commands, and refinement flags in
   the project and final listing. A Jana magnetic-parent conversion has been
   observed to make ADPs isotropic, keep coordinates fixed, and add a global ADP
   restriction. That restriction can still copy one site's tensor to other
   sites after changing the ADP type. Inspect the fitted `.m40` to confirm the
   site-specific values survived. Harmonic displacement parameters may be
   isotropic or anisotropic. Verify the tensor components and active flags.
3. Compare magnetic models with the nuclear values and anchored scales fixed
   initially. If the magnetic model is supported, release the parent-linked
   ADPs first, then the symmetry-allowed parent coordinates. Replace a global
   position lock with the required site equations when releasing coordinates.
   At each stage check the active parameter count, Cartesian tensor eigenvalues,
   final shifts, correlations, and the stability of the moments and domain
   fractions. Preserve the previous fit as a reference.

## Model comparisons and prediction

- Inspect allowed moment components and relative phases from the representation
  analysis. Verify the actual model generated by Jana, including its setting
  and the active components on each site. When screening models, check which
  strong magnetic reflections have zero calculated amplitude. Investigate
  whether each zero follows from symmetry, polarization, or a particular
  moment arrangement or cancellation. Listing precision can also round a small
  amplitude to zero.
- Compare weighted residuals and amplitude residuals on identical observation
  tags and separate the magnetic subset from the fundamentals. Keep the same
  form factor, normalization, and observation-selection policy across trials.
  Record any differences in free parameter count. Retain weak and negative
  observations where the chosen fitting objective supports them.
- For orientational domains, check the matrices in the actual cell and combine
  incoherent domain intensities with normalized fractions. Compare fixed or
  refinable fractions consistently across models and check correlations before
  interpreting the fitted populations. To isolate moment direction, keep the
  relative spin pattern and vary its direction in Cartesian space. Verify
  which magnetic symmetry can support each candidate. Use reflections with
  scattering vectors sensitive to the tested directions.
- To test prediction, hold out complete symmetry families, keeping measurements
  of equivalent reflections together. Fit each model on the training subset
  and evaluate the held-out subset with the fitted parameters fixed. Check the
  listing for zero free parameters in the evaluation and verify that the
  pooled predictions cover each observed test tag exactly once. If an
  all-observation fit serves as a comparator, label it as such because it saw
  the test observations.
